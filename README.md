# P-gina-Informativa-em-HTML-
Esta é a minha primeira página em HTML!! Feita no dia 12 de agosto, para uma atividade da professora Suzana Lustosa, da disciplina de Lab. de Desenvolvimento Web.

Nesta atividade, iniciei meus conhecimentos com HTML.

Para contextualizar, baseei minha página informativa em um conteúdo sobre um caso que acho muito interessante, que é conhecido como o pior erro de software da história: o Therac-25.
Para mais informações, leia minha página informativa!!

De início, utilizei max-width: 700px para definir a largura máxima do conteúdo na tela; width: 100%, que faz o elemento ocupar 100% da largura disponível para ele, respeitando o limite máximo definido; text-align: center, para centralizar o texto dentro do elemento; margin: 0 auto, para centralizar horizontalmente o elemento caso exista espaço disponível nas laterais; display: grid, que ativa o sistema de layout chamado CSS Grid, o qual vai permitir organizar os elementos dentro de um contâiner, e por último utilizei o place-items: center, que centraliza os itens dentro dessa grade, tanto horizontalmente quanto verticalmente, em cada área ocupada pelos itens.

Após isso, para o corpo do código, apenas utilizei elementos para título e subtítulo, elemento p para organizar os parágrafos e <img src=“ ”> para adicionar um PNG da Therac.
